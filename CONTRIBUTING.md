# Contribuer / Contributing

## Français

Pour signaler un problème, ouvrez une issue avec la version, le navigateur, l’appareil, l’outil concerné, les étapes et le résultat attendu. Utilisez un projet de test. Ne joignez pas de JSON, ZIP ou capture contenant des documents privés sans les avoir anonymisés.

Le fichier de travail est `index.html`. Il n’y a pas de compilation. Préservez les formats existants, les contrôles de messages entre fenêtres et l’isolation des données. Les images Farde ne doivent pas être ajoutées au JSON global. Vérifiez une modification avec des données de test sauvegardées, puis documentez-la dans l’historique.

Les modifications de code sont proposées sous GNU AGPL v3.0 ou ultérieure ; la documentation sous CC BY-SA 4.0, sauf mention contraire. Les marques restent réservées.

## English

Report issues with version, browser, device, affected tool, reproduction steps and expected outcome. Use test data and remove private content from attachments.

Edit `index.html`; no build step is required. Preserve existing formats, cross-window message checks and data isolation. Keep Farde images out of the global JSON. Verify changes with backed-up test data and update the changelog.

Code contributions use GNU AGPL v3.0 or later; documentation uses CC BY-SA 4.0 unless otherwise stated. Trademarks remain reserved.
