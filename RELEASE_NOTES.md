# Projets v0.12.0 — Intégration GitHub Pages

Texte préparé pour une préversion. À publier après le contrôle des ouvertures et sauvegardes sur GitHub Pages.

## Français

Projets rassemble les outils Eigrutel Lab dans des espaces de travail organisés par projet.

- Couvertures et couleurs personnalisables ; navigation repliable.
- Raccordement de Personnages, Boussole, Univers, Scénoscope, Comic Script, 7 Questions, Pop!, WIP et Farde.
- Consultation de Narratopedia dans l’espace du projet.
- Sauvegarde locale et échange des données compatibles par JSON.
- **Farde : ZIP séparé à conserver avec le JSON Projets.**

Pas de compte ni de synchronisation automatique. Les données locales ne suivent pas un changement d’adresse ou d’appareil : exportez vos sauvegardes avant migration.

## English

Projets groups Eigrutel Lab tools into project workspaces, with custom covers and colours, collapsible navigation, connected tools and local JSON backups. Narratopedia is available for consultation.

**Farde remains a separate ZIP backup; keep it alongside the project JSON.** There is no account or automatic synchronisation. Export your files before changing browser, device or hosting origin.
